SIMCRAFT — CAS RELEASE CANDIDATE (pre-release)
Buildcraft tab is visible and displays COMING SOON only. Full Build Studio is reserved for the first post-release update.

CAS additions in this candidate:
- Hair & Glasses tab: catalog-based hairstyle ranking from manually entered hair descriptions.
- Settings tab: export/import project preferences and catalog JSON.
- Buildcraft placeholder tab.
- Existing Smart Face Hover and CC scanner retained.

IMPORTANT LIMITATIONS
- Hair matching is based on user-written descriptions and catalog metadata, not image recognition.
- Character projects do not yet embed reference images or nested iframe editor state.
- No direct in-game CAS automation, validated face-template matching, or game-ready package export.
- GitHub auto-updater still requires a signing key, published releases and Windows end-to-end testing.
- Windows EXE is carried forward from v5.8; its bundled browser workspace is updated. The EXE icon resource is not yet embedded.
- Mac package is a build kit, not a compiled app; macOS updater not implemented.
- This build has NOT been tested on Windows or macOS; do not claim a production-ready release.
