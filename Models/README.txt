SimMorph Studio v2.1 - Face landmark model directory

Place a compatible MediaPipe face_landmarker.task file here.
The model manager checks for the file and its size. It does NOT run landmark inference yet.
The game CAS face presets in Assets/FaceTemplates are reference images, not trained models.
No AI model weights are included in this build.

Official MediaPipe model information:
https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker
