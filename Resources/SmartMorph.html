What works and what is still planned

  • Working: original-resolution image import, optional 2× image enlargement, sharpening, per-tab framing, zoom, face-center selection, PNG export, and editable JSON plans.
  • Experimental: automatic face framing uses the browser's FaceDetector API if available; manual click always works.
  • Not yet implemented: genuine similarity-ranked F1–F19/M1–M19 template recognition, photo-derived slider values, automatic in-game CAS changes, or CC matching. One-shot prepares a plan; it does not morph the game.
