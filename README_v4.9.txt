CASCraft Studio v4.9 — UV Face Alignment Lab

New: UV Face Alignment v4.9 menu opens a local browser-based alignment workspace.
Load a reference photo and a UV guide/target texture, reposition, scale, rotate, feather, and export a transparent PNG draft and settings JSON.
The app does not automatically generate a game-ready Sims 4 texture or package. A real UV guide from the selected CAS mesh and in-game validation are necessary.
Windows EXE cross-compiled on Linux; not runtime-tested on Windows.
