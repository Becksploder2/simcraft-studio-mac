MAC BUILD KIT (not a precompiled Mac app)

On a Mac: install Xcode Command Line Tools (xcode-select --install), unzip this archive, double-click Build_on_Mac.command (or run bash Build_on_Mac.command in Terminal). It builds CASCraft Studio.app locally. The app has NOT been compiled or tested on macOS here. It is unsigned and unnotarized; Gatekeeper may block sharing. Test on your own Mac before giving it to your friend.

This is a prototype: glasses creator outputs 2D PNG and JSON, not Sims 4 3D CC or .package files.
