CASCraft Studio v4.7 — macOS build kit

On a Mac with Xcode command line tools, run Build_on_Mac.command to compile CASCraft Studio.app.
Open SmartMorph / Photo Studio from the app menu. SmartMorph opens in your default browser.

Working in photo workspace: import, optional image enhancement, separate tabs, framing and zoom, export PNG and JSON.
One-shot mode prepares a plan only; it does not modify The Sims 4. The Mac app is not compiled or tested in this Linux environment.
